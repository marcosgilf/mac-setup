# zsh configuration

Opinionated zsh setup for interactive development shells.

Included behavior:

- Starship prompt with shared Tokyo Night colors
- fzf, zoxide, eza, bat, fd, and ripgrep integration
- autosuggestions, syntax highlighting, history search, and vi mode
- modular functions loaded from `functions/`

Put machine-only functions in `functions/local/`. That directory is ignored.
